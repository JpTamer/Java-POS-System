# Java POS System ☕

A terminal-based Point of Sale application for inventory and sales management, built entirely from scratch in core Java.

### 🏗️ Architecture & Design
* **Core Java:** Built without external frameworks to demonstrate a deep understanding of standard Java libraries.
* **Object-Oriented Programming (OOP):** Strictly adheres to OOP principles with dedicated classes for products, inventory, and transactions utilizing encapsulation, inheritance, and polymorphism.
* **Data Structures:** Leverages the Java Collections Framework for optimized product lookup and real-time sales tracking.
* **Clean Code:** Follows SOLID principles to ensure responsibilities are separated and the codebase remains modular and maintainable.

### 🚀 Key Features
* Fast, lightweight terminal interface.
* Efficient inventory management and low-latency transaction processing.
* Modular design structured for future GUI or relational database integration.
